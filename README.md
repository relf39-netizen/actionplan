# ระบบแผนปฏิบัติการประจำปีและจัดสรรงบประมาณโรงเรียน
### (School Annual Operational Plan & Budget Allocation System)
พัฒนาสำหรับโรงเรียนระดับการศึกษาขั้นพื้นฐาน (สพป. / สพม. / สพฐ. กระทรวงศึกษาธิการ)

---

## 📌 จุดเด่นและวัตถุประสงค์
1. **จัดเก็บข้อมูลพื้นฐานโรงเรียนและข้อมูลนักเรียน** แยกตามระดับชั้น (อนุบาล 1 - ประถม 6) ชาย/หญิง และคำนวณยอดรวมอัตโนมัติ
2. **ประมาณการรายรับตามเกณฑ์ สพฐ.** (เงินอุดหนุนรายหัว, Top Up โรงเรียนคุณภาพ, หนังสือเรียน, เครื่องแบบ, อุปกรณ์, กิจกรรมพัฒนาผู้เรียน, ปัจจัยพื้นฐานนักเรียนยากจน กสศ., อาหารกลางวัน อปท., รายได้สถานศึกษา) ในรูปแบบคล้ายสเปรดชีต Excel
3. **จัดสรรงบประมาณตามฝ่าย/งาน** (วิชาการ, งบประมาณ, บุคคล, บริหารทั่วไป, งบกลาง) พร้อมระบบตรวจสอบผลรวม 100% อัตโนมัติ
4. **จัดสรรงบกิจกรรมพัฒนาผู้เรียน 4 กิจกรรมหลัก** พร้อมระบบตรวจสอบ 100%
5. **จัดทำโครงการตามแผนปฏิบัติการประจำปี** บันทึกหลักการ วัตถุประสงค์ ตัวชี้วัด วิธีดำเนินงาน และรายละเอียดค่าใช้จ่าย (จำนวน x ราคาต่อหน่วย = รวมเงิน)
6. **ระบบตรวจสอบและควบคุมงบประมาณ** ป้องกันการเบิกจ่ายเกินงบประมาณ (Over-budget Alert) คำนวณยอดคงเหลือแบบเรียลไทม์
7. **เชื่อมโยงยุทธศาสตร์ กลยุทธ์ เป้าประสงค์ ตัวชี้วัด** สู่แผนปฏิบัติการประจำปี
8. **Dashboard กราฟิกและสถิติด้วย Chart.js**
9. **ระบบรายงานและ Export** พิมพ์เอกสาร, ส่งออก Excel (.xlsx) และ PDF (.pdf)
10. **ระบบสิทธิ์ผู้ใช้งาน (RBAC)**: Administrator, ผู้อำนวยการโรงเรียน, ครู/ผู้รับผิดชอบโครงการ

---

## 🛠️ ความต้องการระบบ (System Requirements)
- **Web Server**: Apache / Nginx / LiteSpeed (รองรับ cPanel / DirectAdmin / Plesk)
- **PHP Version**: PHP 8.0, 8.1, 8.2 หรือ 8.3
- **PHP Extensions**: `pdo`, `pdo_mysql`, `mbstring`, `json`, `session`
- **Database**: MySQL 5.7 / 8.x หรือ MariaDB 10.4+
- **Web Browser**: Google Chrome, Microsoft Edge, Mozilla Firefox, Safari

## 🚀 คู่มือการติดตั้งบน cPanel / Shared Web Hosting

### ขั้นตอนที่ 1: อัปโหลด Source Code
1. เข้าสู่ระบบ **cPanel** ของผู้ให้บริการโฮสติ้ง
2. ไปที่เมนู **File Manager (ตัวจัดการไฟล์)**
3. เข้าไปที่โฟลเดอร์ `public_html` (หรือโฟลเดอร์ของ Subdomain เช่น `plan.yourschool.ac.th`)
4. อัปโหลดไฟล์ ZIP ของโปรเจกต์ทั้งหมด จากนั้นคลิกขวาแล้วเลือก **Extract (แตกไฟล์)**

### ขั้นตอนที่ 2: สร้างฐานข้อมูล MySQL และ User
1. ในหน้าหลัก cPanel ไปที่เมนู **MySQL® Databases (ฐานข้อมูล MySQL)**
2. ในส่วน **Create New Database**:
   - ตั้งชื่อฐานข้อมูล เช่น `school_budget_db`
   - คลิกปุ่ม **Create Database**
3. ในส่วน **MySQL Users (Add New User)**:
   - ตั้ง Username เช่น `school_user`
   - ตั้งรหัสผ่านที่ปลอดภัย (Password) และจดบันทึกไว้
   - คลิก **Create User**
4. ในส่วน **Add User to Database**:
   - เลือก User และ Database ที่เพิ่งสร้าง
   - คลิก **Add**
   - ติ๊กเลือก **ALL PRIVILEGES (สิทธิ์ทั้งหมด)** แล้วกด **Make Changes**

### ขั้นตอนที่ 3: นำเข้าไฟล์ SQL (Import Database)
1. กลับมาที่หน้าหลัก cPanel เข้าเมนู **phpMyAdmin**
2. เลือกชื่อฐานข้อมูลที่เพิ่งสร้างไว้ทางแถบซ้ายมือ
3. คลิกแท็บ **Import (นำเข้า)** ด้านบน
4. กดปุ่ม **Choose File** แล้วเลือกไฟล์ `database/schema.sql` กด **Go (ดำเนินการ)**
5. ทำซ้ำขั้นตอนเดิม โดยเลือกไฟล์ `database/seed.sql` เพื่อนำเข้าข้อมูลตัวอย่างเริ่มต้น

### ขั้นตอนที่ 4: กำหนดค่าการเชื่อมต่อฐานข้อมูล
1. เปิดไฟล์ `config/database.php` ด้วย Text Editor ใน File Manager
2. แก้ไขค่าตัวแปรให้ตรงกับฐานข้อมูลที่สร้างไว้:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'ชื่อ_cpanel_school_budget_db');
define('DB_USER', 'ชื่อ_cpanel_school_user');
define('DB_PASS', 'รหัสผ่านที่คุณตั้งไว้');
define('DB_PORT', 3306);
define('DB_CHARSET', 'utf8mb4');
```
3. บันทึกไฟล์ (Save Changes)

## 📊 สูตรการคำนวณสำคัญในระบบ

1. **จำนวนนักเรียนรวม**:
   $$\text{รวม} = \text{นักเรียนชาย} + \text{นักเรียนหญิง}$$
   $$\text{นักเรียนทั้งหมด} = \sum (\text{รวมแต่ละชั้นปี})$$

2. **ประมาณการรายรับแต่ละรายการ**:
   $$\text{จำนวนเงิน} = \text{จำนวนผู้มีสิทธิ์} \times \text{อัตราต่อคน}$$

3. **จัดสรรงบประมาณตามฝ่ายงาน**:
   $$\text{งบประมาณที่จัดสรร} = \text{งบประมาณรวม} \times \frac{\text{เปอร์เซ็นต์}}{100}$$
   *(โดยที่ $\sum \text{เปอร์เซ็นต์} = 100\%$)*

4. **งบประมาณโครงการ**:
   $$\text{ค่าใช้จ่ายแต่ละรายการ} = \text{จำนวน} \times \text{ราคาต่อหน่วย}$$
   $$\text{งบประมาณรวมโครงการ} = \sum (\text{ค่าใช้จ่ายทุกรายการ})$$

5. **งบประมาณคงเหลือ**:
   $$\text{งบประมาณคงเหลือ} = \text{งบประมาณที่ได้รับ} - \text{งบประมาณที่ใช้ไปจริง}$$

## 🛡️ มาตรการความปลอดภัย
- ใช้งาน **PDO Prepared Statements** ครบถ้วน ป้องกัน SQL Injection 100%
- เข้ารหัสผ่านด้วย **bcrypt (password_hash)**
- ตรวจสอบสิทธิ์ **Role-Based Access Control (RBAC)** ในทุกส่วนงาน
- ป้องกัน Cross-Site Scripting (XSS) ด้วย `htmlspecialchars()`
- ป้องกัน CSRF Attacks ด้วยการตรวจสอบ Anti-CSRF Token
